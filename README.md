# Elias Castro — Landing

Landing page do portfólio e apresentação comercial de **Elias de Castro Alves** (marca **Elias Castro**).

## Stack

- Next.js (App Router) + React + TypeScript + Tailwind CSS
- Framer Motion + Lucide + Simple Icons
- Contato: formulário nome + mensagem → redireciona ao WhatsApp (`wa.me`)
- Sem backend nesta fase

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).
